3. Sorting


| Algorithm          | Best Case Time | Average Case Time | Worst Case Time | Space Complexity | In-place | Stable | Notes                                                 |
| ------------------ | -------------- | ----------------- | --------------- | ---------------- | -------- | ------ | ----------------------------------------------------- |
| **Selection Sort** | O(n²)          | O(n²)             | O(n²)           | O(1)             | ✅        | ❌      | Always scans full list for smallest element each pass |
| **Bubble Sort**    | O(n)           | O(n²)             | O(n²)           | O(1)             | ✅        | ✅      | Can stop early if no swaps in a pass                  |
| **Insertion Sort** | O(n)           | O(n²)             | O(n²)           | O(1)             | ✅        | ✅      | Efficient for small or nearly-sorted arrays           |
| **Merge Sort**     | O(n log n)     | O(n log n)        | O(n log n)      | O(n)             | ❌        | ✅      | Consistent performance, good for linked lists         |
| **Quick Sort**     | O(n log n)     | O(n log n)        | O(n²)           | O(log n)         | ✅        | ❌      | Worst case avoided with good pivot choice             |
| **Heap Sort**      | O(n log n)     | O(n log n)        | O(n log n)      | O(1)             | ✅        | ❌      | Uses heap data structure                              |


If you want, I can also give you a **condensed quick-reference chart** for remembering these in exams/interviews.


* **Stable** → Keeps the **relative order** of equal elements the same as in the input.
  Example: Sorting `[(4,a), (3,x), (4,b)]` by number → stable sort gives `[(3,x), (4,a), (4,b)]` (a stays before b).

* **In-place** → Uses **O(1) or constant extra memory** (doesn’t make a full copy of the array), sorting mostly by swapping elements in the original array.

So:

* Stable → preserves order of equal values.
* In-place → minimal extra space usage.


#### Sorting Algorithms in short
1. Selection - Go from left to right, for each position scan right - find the smallest element and replace.
2. Bubble - From left to right start from i and compare and put the bigger element to the right, now loop over from i+1 and continue.
3. Insertion - Bagal khujana, Search back and until you get the right position to put the element and till that keep moving the elements forward.
