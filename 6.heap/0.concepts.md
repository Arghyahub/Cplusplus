# Heap in arrays

A heap can also be formatted in an array where for node i, its child are in `i*2` and `i*2+1`
Heap sort works in the manner where you compare from end node and swap its way upward

Use the same idea for insertion in heap and pop

Insert -> Insert at end and heap sort it upward
Pop -> Move the last element at the top and heap sort in the opposite direction(downward).

In downward direction always swap with the child having largest/smallest value
