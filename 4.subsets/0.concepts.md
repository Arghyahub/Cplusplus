Lets skip skip similar number but atleast for the first turn we will take them, this will ensure that we generate all sets starting from a position

```cpp
void solve(vector<int>& nums, int i){
    ans.push_back(tmp);
    for (int j=i; j<nums.size(); j++){
        if (j!=i && nums[j]==nums[j-1]) continue;
        tmp.push_back(nums[j]);
        solve(nums,j+1);
        tmp.pop_back();
    }
}
```
