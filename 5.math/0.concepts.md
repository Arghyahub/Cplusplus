# XOR Patterns in C++ for DSA

## 1. Basic XOR Properties
- `a ^ a = 0`
- `a ^ 0 = a`
- XOR is **commutative**: `a ^ b = b ^ a`
- XOR is **associative**: `(a ^ b) ^ c = a ^ (b ^ c)`

---

## 2. Find the Unique Element (Others Appear Twice)
**Use case:** One number appears once, others twice  
```cpp
int x = 0;
for (int v : arr) x ^= v;
```
